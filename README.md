# Excel 密碼批次產生工具（Excel Password Filler）

用 **Python** 開發的桌面小工具，用來解決硬體出貨流程中「每台裝置都要有一組獨立密碼」卻只能手動輸入、容易出錯又浪費時間的問題。

## 專案背景

在硬體／IoT 裝置出貨作業中，每一台裝置都需要依據自己的**序號（SN）**與**MAC 位址**產生一組獨一無二的密碼，並登記在 Excel 對照表中，供後續產線或客服查詢。這件事原本是人工一筆一筆計算、貼上，量一大就很容易出錯或漏做。

這個工具讓使用者只要選好 Excel 檔案、指定 SN 和 MAC 是哪一欄，按一個按鈕，就能一次幫全部資料列產生密碼並直接寫回原檔案。

## 功能特色

- **一鍵批次處理**：讀取整份 Excel，自動逐列產生密碼並寫回，不用手動計算
- **智慧欄位偵測**：自動辨識並預先選好「SN」「MAC」欄位（依標題關鍵字判斷），減少人工設定
- **安全防呆**：已有密碼的列會自動跳過，不會覆蓋既有資料；資料不完整的列會列出警示但不中斷整體流程
- **即時執行紀錄**：處理過程與結果（成功筆數、跳過筆數、錯誤列）即時顯示在介面上
- **獨立執行檔**：打包成不需安裝 Python 環境即可直接執行的 `.exe`，方便非技術人員在產線電腦上使用
- **中 / 英雙語版本**：分別提供中文與英文介面版本，因應不同使用者需求

## 使用的技術

| 項目 | 說明 |
|---|---|
| 語言 | Python 3 |
| GUI | Tkinter（含 ttk 元件） |
| Excel 讀寫 | openpyxl |
| 並行處理 | threading（背景執行避免介面卡住） |
| 打包發佈 | PyInstaller（產出免安裝的 Windows 執行檔） |

## 做了什麼

協助設計並完成整個工具，包括：
- 設計密碼產生演算法，依 MAC + SN 組合運算出符合強密碼規則（英文大小寫、數字、特殊符號皆需具備）的 12 碼密碼
- 設計圖形化操作介面，讓沒有程式背景的使用者也能上手
- 處理 Excel 讀寫的邊界情況（空欄位、缺欄位、檔案被占用中等）並提供對應提示
- 將專案打包成獨立執行檔，交付給實際使用單位（產線／出貨人員）日常使用

## 操作流程（示意）

1. 開啟程式 → 選擇 Excel 檔案
2. 確認 SN／MAC 對應欄位
3. 按下「產生密碼並寫回 Excel」
4. 系統自動完成批次運算並將密碼寫回 Excel 的「密碼」欄
